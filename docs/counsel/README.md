# Counsel instructions

One file per open legal gate, written so it can be handed to qualified counsel
without a conversation first. Each states what the project does today, what it
proposes to do, and the specific questions whose answers change the code.

**These are questionnaires, not legal advice, and not authorization.** Nothing
in this directory clears processing, publication or an external message. A
completed instruction becomes authority only when counsel has answered it and an
authorized human has recorded the decision — the decision record at the foot of
each file is where that goes, and until it is filled in the affected work stays
on hold.

They are drafted in the open for the same reason the rest of the repository is:
a reader deciding whether to trust the output can see which questions the
project knows it has not answered. Detailed advice, holdings inventories and
anything naming a real entity stay out of here and in whatever channel counsel
asks for; these files carry the question and the published counts behind it.

The format follows the gate templates in
[`docs/automation/handoffs.md`](../automation/handoffs.md).
