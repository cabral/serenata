# Scope

The scope of this project lives at the root of the repository:
[`scope.md`](../../scope.md).

It used to live here too, as a byte-identical second copy. Two files that have
to agree eventually stop agreeing, and the first edit after that is a project
with two scopes and no way to tell which one is meant. So this is a pointer.

The root copy is the canonical one because the whole repository is this project
now, not only the `crony-eu/` tree:
[ADR-0014](../../docs/adr/0014-replace-serenata-with-crony.md) records the
replacement of Serenata Europa, and
[`docs/transition-ledger.md`](../../docs/transition-ledger.md) says what happens
to each piece of what it replaces.
